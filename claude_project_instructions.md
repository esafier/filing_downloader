# Instructions for Claude and ChatGPT projects

You do not need to edit each project. Every ticker folder carries
`00_START_HERE.md` (role, how to analyze, style) and `RESEARCH_GUIDE.md`
(where to find things, how to cite, where to save). One paste in your account
settings tells every project, old or new, to read them.

## 1. Paste once into your account settings

- **Claude:** Settings > Profile > "What personal preferences should Claude
  consider in responses?"
- **ChatGPT:** Settings > Personalization > Custom instructions.

Text to paste:

> When a project or chat has one of my ticker research folders attached (a
> folder named like "NVDA - NVIDIA Corp" containing 00_START_HERE.md), open
> 00_START_HERE.md first and follow it before answering: it gives your role,
> the files to read, and when to use Quartr for transcripts, slides and
> anything newer than the local files. If the project's own instructions
> disagree with that folder about where documents are, trust the folder; the
> project's instructions still decide what task to do.

## 2. Optional per-project line

Only if a project ignores the preference, put this one line in its
instructions:

> Read 00_START_HERE.md in the connected folder first and follow it.

## Editing the instructions for every folder

Change `Tickers\_00_START_HERE.md` (role and style) or
`Tickers\_RESEARCH_GUIDE.md` (routing). The next add, rebuild or weekly
refresh copies the change into every ticker folder. A `CLAUDE.md` or
`AGENTS.md` you write yourself inside a ticker folder is never touched.
